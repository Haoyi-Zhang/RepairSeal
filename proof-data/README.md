# Frozen proof-DAG study data

`structured-study.json` is the aggregate scientific record. It is regenerated by
`tests/structured_study.py` and compared during `tests/reproduce_all.py` after
removing only environment-specific time, peak-RSS, and generation-timestamp fields.

Deterministic directories:

- `fixture-certificates/`: 80 full-vector certificates.
- `stress-certificates/`: 300 full-vector certificates.
- `stress-inputs/`: 300 generated stress requests.
- `controls/`: representative full-vector corruptions.
- `refutation-witnesses/`: 285 compact one-point refutation certificates.
- `refutation-controls/`: representative compact-certificate corruptions.

Complete control records are in `tamper-controls.json` (6,000 full-vector
mutations), `refutation-controls.json` (2,850 compact mutations), and
`acceptance-misuse-controls.json` (95 forged refutations of accepted requests).
The aggregate JSON stores SHA-256 indexes over deterministic result and control
records so a clean reproduction checks the complete populations, not only saved
representatives.

Timing files are descriptive and expected to change across hosts. The decisive
semantic-work comparison is deterministic: on the 20 correct fixtures, the
full-vector checker and certificate-free topological evaluator both perform 45,198
node--point operations; recursive reconstruction performs 309,582. Compact
refutation checking evaluates one of the 81 domain points and therefore uses 1/81 of
the full-vector semantic cells for the same request.
